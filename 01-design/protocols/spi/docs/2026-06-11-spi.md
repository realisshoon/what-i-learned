# 2026-06-11 SPI

## Goal
SPI master/slave RTL을 구현하고 serial clock 기반 데이터 이동을 확인한다.

## What I Learned
- SPI는 SCLK, MOSI, MISO, CS의 edge 관계가 동작을 결정한다.
- master가 clock과 chip select를 제어하므로 slave는 edge와 enable 조건에 민감하다.

## Implementation
- `spi_master.sv`, `spi_slave.sv`, `tb_spi_master.sv`를 `code/protocol/spi`에 정리했다.
- SPI/I2C 통합 variant는 별도 `code/protocol/spi-i2c` 폴더로 분리했다.

## Debugging Note
- CPOL/CPHA 가정과 sampling edge를 testbench와 맞췄다.
- CS 비활성 상태에서 shift register가 잘못 움직이지 않는지 확인했다.

## Verification Point
- master transmit data가 slave에서 같은 bit order로 수신되어야 한다.
- CS active 구간 밖에서는 데이터가 무시되어야 한다.

## Summary
SPI 검증은 clock edge, chip select window, bit order를 함께 확인해야 한다.
