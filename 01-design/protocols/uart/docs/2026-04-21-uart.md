# 2026-04-21 UART

## Goal
UART 송수신 기본 구조와 loopback 동작을 구현한다.

## What I Learned
- UART는 baud tick, start bit, data bit, stop bit 순서가 핵심이다.
- loopback 구조는 송수신 타이밍을 동시에 확인하기 좋은 실습이다.

## Implementation
- `uart.v`, `uart_loopback.v`, debounce helper를 `code/protocol/uart`에 정리했다.
- UART 단위 testbench와 TX bit count testbench를 함께 보관했다.

## Debugging Note
- baud rate tick이 bit sampling 위치와 맞는지 확인했다.
- start/stop bit가 깨지면 frame 전체가 밀리는 문제를 파형으로 확인했다.

## Verification Point
- 1 byte 송신 후 수신 데이터가 동일해야 한다.
- idle 상태, start bit 검출, stop bit 복귀를 확인한다.

## Summary
UART 검증은 bit timing과 frame boundary를 정확히 보는 것이 핵심이다.
