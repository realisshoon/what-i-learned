# 2026-04-09 Counter

## Goal
클럭 기반 카운터와 FND 표시 흐름을 구현하고 검증한다.

## What I Learned
- 순차논리는 클럭과 리셋 조건이 동작의 기준이 된다.
- 큰 카운터는 tick enable을 분리하면 설계와 검증이 쉬워진다.

## Implementation
- `counter_10000.v`, `control_unit.v`, `button_debounce.v`를 주제별 counter 폴더로 정리했다.
- FND 출력용 `fnd_controller.v`와 상위 연결용 `adder_fnd.v`도 함께 보관했다.

## Debugging Note
- reset polarity와 tick 발생 주기를 확인했다.
- 버튼 입력은 debounce 후 상태가 한 번만 바뀌는지 확인했다.

## Verification Point
- reset 후 카운터가 초기값으로 돌아가야 한다.
- terminal count 이후 rollover 조건을 확인한다.
- enable이 꺼진 동안 count 값이 유지되어야 한다.

## Summary
카운터 검증은 reset, enable, rollover 세 조건을 중심으로 보면 된다.
