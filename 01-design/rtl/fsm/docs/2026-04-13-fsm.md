# 2026-04-13 FSM

## Goal
FSM으로 LED 제어와 Mealy sequence detector를 구현한다.

## What I Learned
- FSM은 state register, next-state logic, output logic으로 나누면 읽기 쉽다.
- Mealy 출력은 현재 상태뿐 아니라 현재 입력에도 영향을 받는다.

## Implementation
- `fsm_led.v`와 `set_det_mealy.v`를 FSM 주제 폴더로 정리했다.
- `tb_fsm_led.v`, `tb_set_det_mealy.v`로 상태 전이와 출력 조건을 확인했다.

## Debugging Note
- 상태 전이가 한 클럭 늦게 보이는 점을 파형에서 구분했다.
- 입력 sequence와 expected output이 같은 시점에 비교되는지 확인했다.

## Verification Point
- reset 후 초기 상태가 맞아야 한다.
- 모든 입력 분기에서 next state가 정의되어야 한다.
- 목표 sequence 검출 시점의 출력 pulse를 확인한다.

## Summary
FSM은 상태 전이표를 먼저 세우고 RTL과 testbench를 맞춰가면 안정적이다.
