# 2026-05-29 RV32I APB

## Goal
RV32I CPU와 APB 기반 memory/peripheral access 구조를 연결한다.

## What I Learned
- APB는 setup phase와 access phase를 분리해서 PSEL, PENABLE, PREADY를 관리한다.
- CPU memory access와 bus transaction 사이에 handshake timing을 맞춰야 한다.

## Implementation
- RV32I APB variant RTL과 `APB_Master.sv`, `APB_BRAM.sv`를 `code/soc/rv32i/apb`에 정리했다.
- `tb_apb_master.sv`로 APB transaction 흐름을 확인한다.

## Debugging Note
- PADDR/PWRITE/PWDATA가 setup phase에서 안정적인지 확인했다.
- PREADY가 늦는 case에서 control flow가 유지되는지 점검했다.

## Verification Point
- APB read/write transaction phase가 프로토콜 순서와 일치해야 한다.
- CPU load/store 결과가 APB memory data와 일치해야 한다.

## Summary
CPU와 bus를 붙일 때는 명령 실행 결과와 bus handshake를 동시에 검증해야 한다.
