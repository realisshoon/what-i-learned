# what-i-learned

Digital design, SystemVerilog, verification, protocol, and SoC learning notes.

## Structure

- `daily/`: 수업 일지와 핵심 개념 정리
- `code/`: Vivado 프로젝트에서 추출한 RTL/src와 testbench 코드
- `digital-design/`, `systemverilog/`, `verification/`, `protocol/`, `soc/`, `tools/`: 주제별 개념 정리 공간

Vivado 프로젝트 전체, 빌드 산출물, 시뮬레이션 결과, 캐시, 압축 파일은 저장소에 포함하지 않는다.
