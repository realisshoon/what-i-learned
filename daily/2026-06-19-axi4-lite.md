# 2026-06-19 AXI4 Lite

## Goal
AXI4-Lite master/slave handshake와 custom IP template 구조를 실습한다.

## What I Learned
- AXI4-Lite는 AW/W/B, AR/R channel handshake를 독립적으로 관리한다.
- valid/ready는 양쪽이 동시에 1일 때 transfer가 성립한다.

## Implementation
- `axi4_lite_master.sv`, `axi4_lite_slave.sv`와 관련 testbench를 `code/protocol/axi4-lite`에 정리했다.
- custom IP wrapper 후보는 `ip-template/rtl`에 따로 보관했다.

## Debugging Note
- AW와 W channel이 항상 같은 cycle에 도착한다고 가정하지 않도록 확인했다.
- read data valid와 ready의 handshake 종료 조건을 파형으로 점검했다.

## Verification Point
- write address/data/response channel의 handshake 순서를 확인한다.
- read address/data channel에서 data가 안정적인지 확인한다.

## Summary
AXI4-Lite 검증은 각 channel의 valid/ready handshake를 독립적으로 추적하는 것이 핵심이다.
