# 2026-05-19 RV32I CPU

## Goal
RV32I single-cycle CPU의 datapath, control unit, instruction/data memory를 구현한다.

## What I Learned
- CPU 설계는 instruction decode, ALU control, register file, memory access가 맞물린다.
- single-cycle 구조는 한 명령이 한 cycle 안에서 완료되도록 critical path를 이해해야 한다.

## Implementation
- `top_rv32i_soc.sv`, `rv32i_cpu.sv`, `rv32i_datapath.sv`, `rv32i_control_unit.sv`를 정리했다.
- instruction/data memory와 `tb_rv32i.sv`를 함께 이동했다.

## Debugging Note
- opcode/funct3/funct7 decode가 instruction format과 일치하는지 확인했다.
- branch/jump 시 PC update 경로를 파형으로 추적했다.

## Verification Point
- R/I/S/B/U/J type 명령의 decode와 writeback을 확인한다.
- load/store address와 data memory write enable을 확인한다.

## Summary
RV32I CPU는 명령어 format별 제어신호가 datapath를 정확히 여는지 검증해야 한다.
