# 2026-06-12 I2C SPI I2C

## Goal
I2C master와 SPI/I2C 통합 구조를 구현하고 프로토콜별 top 연결을 비교한다.

## What I Learned
- I2C는 SDA 양방향 제어와 start/stop 조건이 중요하다.
- 여러 프로토콜을 한 top에서 다룰 때는 mode/control path를 명확히 분리해야 한다.

## Implementation
- I2C 단독 코드는 `code/protocol/i2c`에, SPI/I2C 통합 코드는 `code/protocol/spi-i2c`에 정리했다.
- master/slave top variant는 통합 폴더 아래에 별도 보관했다.

## Debugging Note
- I2C SDA drive/release 타이밍을 확인했다.
- SPI와 I2C가 같은 top에서 선택될 때 제어 신호가 겹치지 않는지 확인했다.

## Verification Point
- I2C start, address, ack, data, stop 순서를 확인한다.
- 통합 top에서 선택된 protocol만 동작해야 한다.

## Summary
프로토콜 통합 설계는 각 bus의 timing rule을 지키면서 top-level 제어를 단순하게 유지해야 한다.
